# app-factory-privacy

앱 공장 앱들의 개인정보처리방침 (GitHub Pages).

- 앱마다 `<slug>/index.html` 한 장 (한국어 합니다체 + 영어), 루트 `index.html` 목록에 링크 추가
- 스타일은 ScoreTap 방침 페이지와 동일
- 광고(AdMob)를 쓰는 앱은 광고 섹션을 반드시 포함
- 앱의 `app.json` `extra.privacyPolicyUrl` 과 Play Console 개인정보처리방침 URL 에 `https://<user>.github.io/app-factory-privacy/<slug>/` 를 넣는다
